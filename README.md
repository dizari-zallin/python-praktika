## Лабораторная работа 1. Доставка заказов

Консольная программа на базовых конструкциях Python: переменные, типы, ввод и вывод, условия, циклы и функции.

Для каждого заказа вводятся расстояние и время выполнения. Программа считает среднее время доставки, находит самый быстрый и самый медленный заказ, среднюю скорость, число заказов с опозданием относительно норматива и общий километраж.

Код: `python1/analiz_dostavki.py`.

## Лабораторная работа 2. Заказы доставки

Работа со списками, словарями, строками, поиском и сортировкой.

У заказа хранятся номер, город, расстояние, стоимость и статус. Нужно искать заказы по городу, фильтровать по расстоянию, считать среднюю стоимость и общий километраж, собирать список городов и сортировать заказы по расстоянию.

Код: `python2/zakazy_dostavki.py`.

## Лабораторная работа 3. Система обучения

Классы, наследование и полиморфизм.

Базовый класс `LearningMaterial`, производные `Lecture` (длительность) и `Practice` (число заданий). Общий метод оценивает объём занятия. Класс `Course` хранит набор учебных материалов.

Код: `python3/sistema_obucheniya.py`.

## Лабораторная работа 4. Логистика

Многофайловое приложение: модули, собственные исключения, сохранение состояния в JSON.

У груза хранятся номер, отправитель, получатель, масса и статус. Реализованы создание, смена статуса, поиск, фильтрация, статистика и запись в JSON. Попытка изменить несуществующий груз порождает отдельное исключение.

## Лабораторная работа 5. Грузы

Функции высшего порядка, `lambda`, `filter`/`map` и генераторы.

У груза есть номер, отправитель, получатель, масса, стоимость доставки и статус. Нужно отфильтровать доставленные грузы, получить номера, отсортировать по массе, посчитать общую стоимость, проверить наличие грузов тяжелее порога и сделать генератор грузов выбранного статуса.

## Лабораторная работа 6. Интернет-провайдер

Декораторы, контекстные менеджеры, `dataclass`, `Enum`, аннотации типов и `Protocol`.

Система абонентов, тарифов и подключений. Статусы подключения: активно, приостановлено, отключено. Дополнительно считаются стоимость услуг и самый популярный тариф.

## Лабораторная работа 7. Интернет-провайдер

Рефакторинг монолита по принципам SOLID: одна ответственность, открытость для расширения, подстановка, разделение интерфейсов и инверсия зависимостей.

Операции: подключение клиента, смена тарифа, блокировка и расчёт оплаты. Стоимость считается через разные тарифные стратегии.

## Лабораторная работа 8. Интернет-провайдер

Паттерны в одной предметной области.

`Factory` создаёт домашний, корпоративный и мобильный тариф. `Strategy` считает абонентскую плату, скидку и дополнительные услуги. `Observer` сообщает об изменениях.

## Лабораторная работа 9. Интернет-провайдер

TCP-клиент и TCP-сервер со своим прикладным протоколом на JSON. Сетевой код отделён от сервиса и репозитория, сервер обслуживает несколько клиентов.

Основная сущность — тариф. Специализированная команда ищет тарифы по скорости.

## Лабораторная работа 10. Интернет-провайдер

HTTP и REST: методы GET, POST, PUT, PATCH, DELETE, коды ответов, клиент и тесты.

Ресурс — тариф. Специализированная операция отбирает тарифы по скорости.

## Лабораторная работа 11. Интернет-провайдер

Реляционная модель минимум из трёх таблиц, SQL и выдача статики как в CDN.

Сущность — тариф. Кэшируются результаты расчётов, в качестве статического контента отдаются изображения тарифов.

## Лабораторная работа 12. Система управления задачами

ORM на SQLAlchemy: модели, связи, CRUD, фильтры и транзакции.

Сущности `User`, `Project` и `Task`. Нужно создавать задачи и назначать их пользователям.

## Лабораторная работа 13. Тарифы провайдера

Документы в MongoDB и кэш в Redis.

Документ тарифа: название, скорость, цена, ограничения, услуги, регион и статус. В Redis хранятся популярные тарифы, результаты сравнения и кэш расчёта стоимости.

## Лабораторная работа 14. Тарифы провайдера

REST API на FastAPI с валидацией через Pydantic.

Ресурс `/tariffs`. Поля: название, скорость, цена, трафик, услуги, регион и статус.

## Лабораторная работа 15. Task Manager

Веб-приложение на Flask: HTML на Jinja2, REST API и SQLAlchemy.

Сущности `User`, `Project` и `Task`. Интерфейс управляет проектами и задачами: создание, просмотр, изменение, поиск, фильтрация и сортировка.

## Лабораторная работа 16. Интернет-провайдер

Проект на Django: модели, миграции, ORM, шаблоны и админка.

Сущности: клиент, тариф, услуга, подключение и платёж. Страницы показывают абонентов, тарифы, услуги, подключения и платежи.

## Лабораторная работа 17. Интернет-провайдер

Асинхронный Telegram-бот на aiogram 3: команды, клавиатуры, callback, FSM и работа с данными.

Сущности: клиент, тариф, услуга и платёж. Бот показывает текущий тариф, подключает услугу, выводит историю платежей и меняет тариф.

## Лабораторная работа 18. Интернет-провайдер

Автотесты на pytest: фикстуры, параметризация и подмена зависимостей через mock.

Проверяются регистрация абонента, подключение и смена тарифа, расчёт стоимости и блокировка при задолженности.

## Лабораторная работа 19. Система управления задачами

Три микросервиса общаются по REST: пользователи, задачи и уведомления.

При смене статуса задачи сервис задач отправляет событие сервису уведомлений.

## Лабораторная работа 20. Планировщик задач

Приложение и Redis упакованы в Docker Compose. GitHub Actions собирает проект и прогоняет тесты.

## Лабораторная работа 21. Система управления задачами

Итоговый проект: сущности, API, тесты и контейнер.

Сущности `User`, `Project`, `Task` и `Comment`. У задачи есть приоритет, статус, исполнитель и дедлайн.
